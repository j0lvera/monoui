# monoui

An opinionated set of UI components for React.

The goal of this project is to provide the minimum set of components needed to build an MVP or a simple web application.

The limited amount of options per component is intentional. 

## Goals
* `npm install monoui` should be enough to get started. No style imports, no configuration.
* Components should require a minimum amount of props.
* But, components should be flexible enough to be used in a variety of contexts.
